# The Future Universe

> A world where hands are only for eating, and everything else happens by itself.

The Future Universe is an animated, single-page website that imagines ten technologies that do not exist yet. Each one is shown as a full-screen scene with a detailed 3D-style render, a short story and three key features. Scroll down and watch the future unfold.

## The ten technologies

1. **Thought-Powered World**: control doors, cars and objects by thought alone.
2. **Intelligence in the Air**: an invisible intelligence that knows what you need before you ask.
3. **Blink-Speed Travel**: step through a gateway and arrive anywhere instantly.
4. **Money-Free Abundance**: think of what you need and it appears, for everyone.
5. **The Living School Companion**: a glowing guide that follows every child's curiosity.
6. **Self-Shaping Homes**: living architecture that reshapes and repairs itself.
7. **Nano-Healing Cloud**: microscopic machines that heal the body before you feel pain.
8. **Endless Energy Core**: clean energy that powers a whole city and never runs out.
9. **Self-Driving Cities**: silent pods, delivery drones and robot farms in perfect harmony.
10. **Universe Connection Layer**: a calm human at the center of a living network of stars.

## Features

- Animated starfield background
- Glowing hero title with a smooth entrance
- Scroll-triggered reveal with gentle zoom and parallax
- Soft 3D tilt and glowing border when you hover over an image
- Typewriter effect for the detail text
- Sticky navigation bar and scroll progress bar
- Fully responsive, works on phones, tablets and desktops
- Respects reduced-motion settings for accessibility
- Built with plain HTML, CSS and a little JavaScript, no frameworks

## Run it locally

1. Download or clone this repository.
2. Keep index.html and the images folder side by side.
3. Open index.html in any modern browser.

## Publish it with GitHub Pages

1. Open Settings, then Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select the main branch and the root folder, then save.
4. Your site goes live at the link shown on that page.

## About this project

This is a concept and imagination project. The technologies shown are fictional visions of what the future could look like. The images were created with AI image tools from written prompts.
